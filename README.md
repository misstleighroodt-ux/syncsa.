## 🎯 Overview

SyncSA is a responsive web application built with vanilla JavaScript, HTML, and CSS. It provides a user-friendly interface for managing and synchronizing various services and data streams.

## ✨ Features

- **Responsive Design**: Mobile-friendly interface that works across all devices
- **Interactive UI**: Dynamic user interactions powered by vanilla JavaScript
- **Clean Architecture**: Well-organized codebase with separated concerns
- **Modern Styling**: Contemporary CSS styling for a professional appearance

## 🚀 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/misstleighroodt-ux/syncsa.git
   cd syncsa
   ```

2. **Open the application**:
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js with http-server
     npx http-server
     
     # Using PHP
     php -S localhost:8000
     ```

3. **Access the application**:
   - Navigate to `http://localhost:8000` in your browser
